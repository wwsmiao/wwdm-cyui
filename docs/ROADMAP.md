## 一、近期（1~2 周）：把今天的修复打磨成体验

### 1. 图生图降噪的「预设档位」
- 现状：denoise 已是真实连续梯度（0.5 轻改 / 0.85 强改动 / 1.0 纯重绘），但用户要理解数值语义。
- 方向：图生图参数区提供三档预设按钮「轻微 · 标准 · 大改」（对应 0.5 / 0.7 / 0.9），
  点击即写入 denoise，滑条保留微调能力。
- 涉及：`static/app.js`（渲染参数面板）、`workflows.py SKILLS img2img tip`。

### 2. 图片编辑（edit）模式的改动幅度
- 现状：edit 走官方编辑流（reference_latents + 空画布），denoise 不参与——
  改动强度由模型自决，无法像 img2img 那样精细控制。
- 方向（实验）：edit 提交后对「输出图与参考图」做自动比对，差异过小时自动
  提高采样强度重试一次（自适应重绘），或探索 edit + latent 混合的混合工作流。
- 验收标准：同一张图 +「把背景换成海边」，两次输出应有可感知差异可选。

### 3. 润色多模态的中文输出选项
- 现状：润色模板默认输出英文逗号短语（SD 习惯），对话气泡显示英文。
- 方向：全局设置增加「润色输出语言：跟随输入 / 中文 / 英文」选项；
  附录里同步注入语言要求；DeepSeek 通道同样生效。
- 涉及：`llm.py _fill_placeholders` 的 language 占位符 + 设置页 UI。

### 4. AI 单条输入的边界加固
- 现状：`update_last_ai_user` 把最后一条 source='ai' 的用户消息升级为扩写后提示词。
- 风险点：用户在 AI 发送后、工具提交前手动追加第二条消息时，升级可能命中错条。
- 方向：aiSend 生成一个 `user_mid` 传给 chat_stream → 工具提交时按 mid 精确升级
  （而不是取"最后一条"）；store.update_last_ai_user 保留为兜底。
- 涉及：`assistant.py chat_stream`、`static/app.js aiSend`。

### 5. 队列与进度的统一视图
- 现状：队列 pill 15 秒轮询刷新，队列弹窗手动打开。
- 方向：任务提交后自动弹出迷你进度条（已有全局进度条），多任务时显示
  「第 N/M 张」；任务失败时队列 pill 变红提示。
- 涉及：`app.js refreshStatus / pollJob / setCvProgress`。

## 二、中期（1~2 月）：围绕业务（闲鱼店铺「薇薇的猫」）

### 6. 电商商品图一键工作流
- 业务：ComfyUI 远程代装 + 自研 LoRA（小恩雅等 Z-Image-Turbo 基模）销售。
- 方向：把「商品白底图 → 场景图 → 细节特写 → 主图排版」做成一条 AI 助手
  预设流水线（一次对话产出整套商品图），产出直接落到画布分组。
- 依赖：AI 连续工作已就绪；补「输出自动按技能分组到画布」即可。

### 7. LoRA 管理与试装台
- 方向：设置页增加 LoRA 缩略图与触发词管理（上传 LoRA 自动生成试装对比图）；
  AI 助手可回答「这个 LoRA 适合什么」并直接出样图。
- 依赖：catalog.loras 已有列表；需补 LoRA 元数据（触发词/示例图）存储。

### 8. 批量任务的断点续跑与汇报
- 现状：批量（batch_process）失败项只记 errors，跑完一次性汇报。
- 方向：失败项一键重跑；批量完成后 AI 自动生成「成功 N 张 + 失败清单 + 建议重跑」汇报。

### 9. wwdmui 联动
- 方向：wwdmui v4.0（Flask 管理器）读取 CYUI 的图库接口，展示最近作品；
  或 CYUI 增加一键把作品推送到 wwdmui 的商品目录。
