# ---------------------------------------------------------------------
# 三、⚠ 最容易踩的坑：websocket 与 websocket-client 是两个包
#
# 代码写的是 `import websocket`，但要求模块里有 create_connection()。
# 这只有 websocket-client 提供。若误装成 `pip install websocket`，会得到
# 一个 2011 年的同名老包（0.2.1），导入不报错但缺 create_connection，
# 表现为启动日志反复刷：
#     [WARN] 进度通道断开（module 'websocket' has no attribute
#            'create_connection'），2 秒后重连
# 网页能开、能提交任务，但进度条与实时节点名永远不动。
#
# 正确做法（先卸错的，再装对的）：
#   python -m pip uninstall -y websocket
#   python -m pip install websocket-client==1.9.2
#
# 代理行为（app/comfy.py _ws_worker）：ws 连接显式传 http_proxy_host=None +
# http_no_proxy=[127.0.0.1, localhost]——本地 ComfyUI 强制绕过系统代理
# （Clash 场景进度条不动的根因）；远程地址则跟随环境变量 http_proxy。
# 2026-11-17 已实测本地直连正常。
